===============================================================================
                        QUICK START GUIDE
===============================================================================

Prerequisites:
  • Python 3.8+
  • pip package manager
  • Modern web browser
  • ESP32 or Arduino board (for IoT device)

Step 1 - Install Backend Dependencies:
  $ pip install -r requirements.txt

Step 2 - Start Backend Server:
  $ python backend_server.py
  Server runs on http://localhost:5000

Step 3 - Open Web Interface:
  $ python -m http.server 8000
  Open browser: http://localhost:8000

Step 4 - IoT Device Setup:
  • Install Arduino IDE or ESP-IDF
  • Upload iot_embedded.c to your board
  • Connect GPS, camera, and other modules
  • Configure WiFi credentials in code

Step 5 - Verify System:
  • Check API health: http://localhost:5000/api/health
  • View dashboard: http://localhost:8000
  • Monitor backend logs for incoming data
